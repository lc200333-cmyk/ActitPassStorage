# Встроенные библиотеки иконок

- `spb_icons.bundle` — единый пакет штатных иконок SPB Wallet.
- `third_party/NewIcons.zip` — единый пакет из 957 сторонних иконок для раздела «Сторонние».

Оба файла подключены в `pubspec.yaml` как ресурсы приложения и включаются в сборки Windows, Android и Linux. Распакованные сторонние изображения в состав приложения не добавляются: они читаются непосредственно из ZIP-архива.
